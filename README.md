# Ciğerci Miqqo Dijital Menü

GitHub Pages için hazırlanmış, bağımsız ve mobil odaklı statik menü uygulaması.

## GitHub Pages'te yayınlama

1. Bu klasörün içeriğini GitHub deposunun ana dizinine yükleyin.
2. Depoda **Settings → Pages** bölümünü açın.
3. **Deploy from a branch**, `main` ve `/ (root)` seçeneklerini seçip kaydedin.

Uygulama mutlak yol kullanmaz; hem kullanıcı/organizasyon sayfasında hem proje alt yolunda çalışır.
